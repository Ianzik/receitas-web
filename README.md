# Receitas

Aplicativo gratuito para GitHub Pages. Cadastro, busca por ingredientes, favoritos e backup JSON. Os dados ficam no navegador e não são sincronizados entre aparelhos.

Somente o código do aplicativo está neste repositório. Nenhuma receita pessoal acompanha a publicação.

Para publicar: Settings → Pages → Deploy from a branch → main → /(root).
